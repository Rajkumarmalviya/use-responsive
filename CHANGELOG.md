# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-22

### Added
- Initial release of `useResponsive` hook
- SSR-safe responsive breakpoint detection
- Fully customizable screen names and breakpoints
- Type-safe with full TypeScript support
- Auto-generated boolean flags for each screen name
- Debounced resize handling for better performance
- Memoized return values to prevent unnecessary re-renders
- Default breakpoints for mobile, tablet, and desktop
- Comprehensive JSDoc documentation
- Working examples demonstrating various use cases

### Features
- 🎯 Fully customizable breakpoints
- 🔒 Type-safe with excellent DX
- ⚡ SSR-safe for Next.js and other frameworks
- 🪶 Lightweight with zero dependencies
- 🎨 Great autocomplete support
